# Проект: "Визуализация игры Жизнь (Game of Life) на языке C"

Этот проект представляет собой реализацию игры "Жизнь" (The Game of Life) на языке C, с использованием символьной (ASCII) графики, которая выводится непосредственно в терминал. Целью проекта было создание интерактивной программы с настройкой скорости игры и возможностью управления игровым полем. Также предусмотрено использование файлов для быстрой инициализации состояния игры.

## Quest: Разработка игры Жизнь

- **Описание**: Реализована программа на языке C, которая визуализирует игру "Жизнь". В программе используется символьная графика для отображения состояния клеток на поле размером 80x25. 
- В игре предусмотрены следующие особенности:
  - **Замкнутое поле**: поле отображается как прямоугольник 80 на 25 клеток, где клетки внизу и справа имеют соседей по верхней и левой границе, соответственно.
  - **Интерактивный режим**: игрок может управлять игрой, настроив скорость ее выполнения через консоль.
  - **Инициализация состояния**: предусмотрена возможность инициализации начального состояния игры через стандартный ввод, с подготовленными файлами для быстрого старта (минимум 5 файлов с различными начальным состоянием).
- Программа работает в терминале и визуализирует изменения состояния клеток, используя только символы ASCII, что позволяет легко взаимодействовать с программой без графического интерфейса.

## Технические детали:
- Использован стандарт C.
- Программа поддерживает настройку скорости через ввод с клавиатуры.
- Все состояния игры могут быть заранее подготовлены в виде файлов для быстрой инициализации.
- Сборка проекта осуществляется с помощью Makefile.

Этот проект демонстрирует умение работать с визуализацией данных в терминале, а также способность разрабатывать интерактивные консольные программы с использованием стандартных инструментов языка C.
